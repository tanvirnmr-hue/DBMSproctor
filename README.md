# ProctorHall - Online Exam Proctoring & Question Bank (DBMS Capstone)
Folders: Backend/ (Flask API) | Database/ (schema.sql; exam.db auto-created) | Frontend/ (index.html)

## Run
    cd Backend
    pip install -r requirements.txt
    python app.py          (or press F5 / Run Python File in VS Code) -> browser opens automatically
